# Exponential growth

**No simulation data:** train only on $f'=f$ and $f(0)=1$;
compare only with the analytical $e^x$. Exact interior values never enter
training. Check $f(1)=2.718281828459$ and follow the
[three-seed validation gate and source notes](../validation.md).

## Problem

Find $f$ on $[-3,3]$:

$$
f'(x)=f(x),\qquad f(0)=1.
$$

Exact solution: $f(x)=e^x$. The initial value selects one solution from $C e^x$.

## Run

After [setup](README.md#install), run:

```bash
uv run learnpdes train exponential --epochs 10000 --points 256
```

Training samples 256 coordinates, plus $x=0$ for the initial condition.
The network learns from the equation, not exact solution values.

![Exponential growth PINN training](../../assets/examples/exponential/training.gif)

Recorded run; not regenerated by this command.

## Loss

For the network $f_\theta$, minimize the squared residual and initial-value error:

$$
\mathcal L =
3\,\operatorname{mean}\big[(f_\theta'-f_\theta)^2\big]
+(f_\theta(0)-1)^2.
$$

Save as `inspect_loss.py` in the repo root; run `uv run python inspect_loss.py`.

```python
import torch
from learnpdes.training import build_problem

torch.manual_seed(0)
model, problem, _ = build_problem('exponential', points=256)
f = model(problem.inputs)
df = problem.partial_derivative(f, problem.x)

physics = (df - f).square().mean()
initial = (f[problem.zero_mask] - 1).square().mean()
loss = 3 * physics + initial

reference, *_ = problem.get_loss('exponential')()
torch.testing.assert_close(loss, reference)
print('Physics:', physics.item(), 'Initial:', initial.item())
```

The [derivative helper](../../learnpdes/model/objectives.py) keeps the gradient graph
for training. Do not wrap residual calculations in `torch.no_grad()`.
The weight `3` is a project setting; constraints are soft penalties.

## Check

The runner reports RMSE, maximum error and relative L2 error against $e^x$
on a separate 201-point grid. Small training loss can hide large errors
between samples. Increase `--points` or `--epochs` and compare these errors.
